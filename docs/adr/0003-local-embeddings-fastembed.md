# 0003. Локальні ембединги через fastembed

Дата: 2026-10-06. Статус: прийнято.

## Контекст

Документи компанії можуть бути конфіденційними, тому повний текст не повинен покидати інстанс. Потрібна модель, що підтримує українську, працює на CPU і запускається в Docker без GPU. Вартість ембедингів для кейсу має бути нульовою. Образ сайдкара не повинен бути надто великим, а холодний старт довгим.

## Рішення

Сайдкар `embedder` (FastAPI, Python 3.12) використовує `fastembed` з моделлю `intfloat/multilingual-e5-small` (384 виміри), підключеною через `TextEmbedding.add_custom_model` (ONNX, mean pooling, нормалізація). Модель вшита в образ на етапі build. Для моделей e5 потрібні префікси `query: ` і `passage: `. fastembed для custom-моделі їх не додає, тому їх додає сам сайдкар залежно від `kind`, а Laravel передає чисті тексти. Інтерфейс `EmbeddingProvider` дозволяє замінити драйвер без зміни коду.

## Альтернативи

| Варіант | Плюси | Мінуси | Чому відхилено |
|---|---|---|---|
| Voyage AI | Вища якість для багатомовних текстів | Платний, тексти йдуть назовні | Не підходить для локального приватного запуску. Лишається альтернативою для production, перемикається драйвером |
| OpenAI embeddings | Проста інтеграція | Платний, тексти йдуть назовні, ще один постачальник | Те саме, що й Voyage, плюс додатковий постачальник |

## Наслідки

Простіше: нуль вартості, повний текст документів лишається в інстансі, до Anthropic ідуть лише релевантні фрагменти. Складніше: якість e5-small на українській може бути нижча за хмарні моделі, а образ сайдкара більший за звичайний. Заміна моделі змінює розмірність і потребує переіндексації чанків. Моніторити: recall@5 на evals, розмір образу, час холодного старту. Драйвер для Voyage описаний як наступний крок у production.
